# Sentinel

Autonomous 4-agent AI system that monitors business data, detects anomalies, diagnoses root cause, and drafts responses, powered by Google Gemini.

**Application code** lives in [`sentinel/`](sentinel/) (backend, frontend, full README). The **`Dockerfile`** in this directory exists so [Railway](https://railway.app) can build the FastAPI backend from the monorepo root without extra dashboard configuration.
